# Seb-GRAF/homebrew-tap

Homebrew casks for [StableBar](https://github.com/Seb-GRAF/StableBar), a native, configurable menu bar for macOS. Install it with `brew install --cask seb-graf/tap/stablebar`. Use the full name: Homebrew only loads casks from taps you trust, so after a plain `brew tap seb-graf/tap`, `brew install --cask stablebar` fails until you run `brew trust seb-graf/tap`. Each stable release of StableBar updates the cask here. StableBar also updates itself, so `brew upgrade` skips it unless you pass `--greedy`. `brew uninstall --zap --cask stablebar` first runs StableBar's own uninstall, which turns off the menu bar auto-hide its setup turned on and removes its login item, `stablebar` command and Keychain items, then deletes its configuration, caches and preferences.
